# 🎯 Mini AimLabs

> A browser-based aim trainer focused on reaction speed, precision and repeatable practice sessions.

## 🎮 Gameplay
- Moving targets and penalty targets
- Streak-based bonus scoring
- 30-second sessions
- Easy / Medium / Hard
- Per-difficulty high scores
- Pause / resume
- Local persistence
